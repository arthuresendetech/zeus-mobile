# Zeus Mobile

Sistema mobile de gestão interna desenvolvido para a Comp Júnior.

O projeto tem como objetivo centralizar e organizar informações internas da empresa, permitindo o gerenciamento de clientes, membros, projetos e indicadores administrativos.

---

## Funcionalidades

- Tela de login
- Navegação entre telas
- Dashboard administrativo
- Gestão de clientes
- Interface responsiva para dispositivos mobile
- Estrutura organizada utilizando Expo Router

---

## Tecnologias utilizadas

- React Native
- Expo
- Expo Router
- TypeScript

---

## Justificativas técnicas

### React Native
Utilizado para desenvolvimento mobile multiplataforma, permitindo criar aplicações para Android e iOS utilizando JavaScript e TypeScript.

### Expo
Escolhido para facilitar o desenvolvimento, testes e execução do aplicativo, além de simplificar a configuração inicial do projeto.

### Expo Router
Utilizado para organizar a navegação entre telas de forma simples e baseada em arquivos.

### TypeScript
Utilizado para melhorar a organização do código e aumentar a segurança durante o desenvolvimento.
