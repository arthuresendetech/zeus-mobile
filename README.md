# Zeus Mobile

Sistema mobile interno desenvolvido para a Comp Júnior.

## Funcionalidades

- Tela de login
- Dashboard inicial
- Listagem de clientes
- Navegação entre telas com Expo Router

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- Expo Router

## Como executar o projeto

```bash
npm install
npx expo start
